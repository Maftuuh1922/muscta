# Quick Firebase Setup

## ⚡ Setup Firebase Firestore (5 Menit)

### 1. Buka Link Ini:
```
https://console.firebase.google.com/project/musicta-9cd36/firestore
```

### 2. Klik "Create database"
- Pilih: **"Start in test mode"** ✅
- Location: **asia-southeast2 (Jakarta)** ✅
- Klik "Create" ✅

### 3. Setup Storage (Optional)
```
https://console.firebase.google.com/project/musicta-9cd36/storage
```
- Klik "Get started"
- Pilih "Start in test mode"
- Same location: asia-southeast2

## 🎯 Yang Gratis di Firebase:

### Firestore Database:
- **50,000 reads/day** 📖
- **20,000 writes/day** ✍️
- **1 GB storage** 💾
- **Unlimited collections** 🗂️

### Storage:
- **5 GB storage** 🖼️
- **1 GB download/day** ⬇️

### Auth:
- **Unlimited users** 👥
- **All providers free** 🔐

## 🚀 Setelah Setup:

1. Run app: `flutter run`
2. Data akan sync otomatis
3. Aplikasi akan jalan online + offline

## 💡 Mode Offline Aktif:

Aplikasi sekarang bisa jalan **tanpa Firestore**:
- ✅ Save profile locally
- ✅ Continue ke main app
- ✅ Auto sync when online
- ✅ No more loading loop!
